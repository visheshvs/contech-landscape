ConTech Landscape

An open, weekly-updated map of the technology companies building for architecture, engineering, construction and operations.

Fig. 1 — One building per category, in lifecycle order, one floor per company. Open steel frames are companies added this week; dashed plots are categories with none yet. Select a building to filter the directory.

{B}

Where the tools sit in a project

Each row is a category and each column a project phase. The stronger the shade, the more companies offer that kind of tool for that phase. Companies span several categories and phases, so they count in every cell they belong to.

Fig. 2 — Companies by category and phase. Select a cell to see those companies in the directory.

{C}

How categories combine

Most companies sit in more than one category. Each column is one exact combination; the bar above it counts the companies with that combination and nothing else. Dots below show which categories are in it, and the bars on the right show each category's total.

Fig. 3 — Exact category combinations, an UpSet plot. Select a column to see those companies in the directory.
